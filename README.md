# 🧪 EazyExp — Padepokan Eksperimen Filter List

> ⚠️ **PERINGATAN KERAS:** Ini adalah ruang pertapaan dan uji coba aturan filter tingkat lanjut. **Tolong jangan diikuti / dipasang sembarangan**, atau tampilan web Anda akan mengalami ***chaos***! 💥🦖

Kumpulan aturan eksperimental (*cosmetic filter*, *scriptlet*, dan *toggle* perilaku situs) yang diracik khusus untuk pemblokir iklan berbasis **browser** seperti **uBlock Origin** atau **AdGuard Browser Extension** *(tidak kompatibel dengan pemblokir level DNS seperti personalDNSfilter, NextDNS, maupun Pi-hole)*.
